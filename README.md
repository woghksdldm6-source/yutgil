# 윷길 — Netlify에 올리기

윷놀이 웹 게임이에요. 혼자서 일곱 상대를 이기는 **혼자 원정**과, 방을 만들어 2~4명이 함께하는 **친구와 하기**가 있어요.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `public/index.html` | 게임 화면 전체 (혼자 원정 + 친구와 하기) |
| `netlify/functions/room.mjs` | 친구와 하기 방 서버 (`/api/room`) |
| `netlify.toml` | Netlify 설정 (게임 화면 폴더, 서버 폴더 위치) |
| `package.json` | 방 서버가 쓰는 라이브러리 목록 (`@netlify/blobs`) |

## 올리는 방법

> **주의:** Netlify 화면에 폴더를 끌어다 놓는 방식(드래그 앤 드롭)으로 올리면 게임 화면은 뜨지만 방 서버가 동작하지 않아서 **친구와 하기가 안 돼요.** 아래 두 방법 중 하나로 올려 주세요.

### 방법 1. GitHub 저장소로 연결 (추천)

1. 이 폴더 전체를 GitHub 새 저장소에 올려요.
2. Netlify에서 새 사이트(프로젝트)를 만들 때 Git 저장소에서 가져오기를 고르고, 방금 만든 저장소를 선택해요.
3. 빌드 명령은 비워 두면 돼요. 필요한 설정은 `netlify.toml`에 들어 있어서 Netlify가 알아서 읽어요.
4. 배포가 끝나면 사이트에 들어가서 첫 화면의 **친구와 하기** 버튼이 눌리는지 확인해요. 눌리면 방 서버까지 제대로 올라간 거예요.

이후에는 저장소에 바뀐 파일을 올릴 때마다 자동으로 다시 배포돼요.

### 방법 2. Netlify CLI로 바로 올리기

Node.js가 깔린 컴퓨터의 터미널에서 이 폴더로 이동한 뒤:

```bash
npm install
npx netlify-cli login
npx netlify-cli deploy --prod
```

처음 실행하면 새 사이트를 만들지, 기존 사이트에 올릴지 물어봐요. 배포할 폴더(publish directory)를 물으면 `public`이라고 답하면 돼요.

## 도메인 연결

Netlify 사이트 설정의 도메인 관리 메뉴에서 가지고 있는 도메인을 추가하고, 안내에 나오는 대로 도메인 업체의 DNS 설정을 바꾸면 돼요. 연결 뒤에는 `https://내도메인/?room=방코드` 링크로 친구를 바로 초대할 수 있어요.

## 친구와 하기 동작 방식

- 방장이 방을 만들면 5자리 방 코드와 초대 링크가 나와요. 친구는 링크를 열거나 코드를 입력해서 들어와요.
- 대기실에서 방장이 사람마다 말 개수(2~4개)와 부적 사용 여부를 정하고 시작해요.
- 부적과 증강을 켜면 각자 3개 중 하나를 골라 들고 시작해요.
- 누군가 첫 골인을 했을 때, 그리고 누군가 골인을 하나 남겼을 때 증강 라운드가 열려서 모두 하나씩 더 골라요. 그 순간 가장 뒤처진 사람에게는 역전 부적(역전의 윷가락, 급행, 설욕, 연타) 후보가 나와요.
- 부적은 일반·희귀·전설 등급이 있고, 후보는 일반 3 : 희귀 2 : 전설 1 비율로 뽑혀요.
- 증강 라운드에서 누가 오래 안 고르면 방장이 남은 사람 것을 무작위로 정할 수 있어요.
- 차례인 사람의 화면이 윷을 던지고 말을 옮긴 결과를 서버에 저장해요.
- 방에 들어오면 브라우저끼리 바로 연결(WebRTC)을 시도해요. 연결되면 친구가 던지거나 옮긴 게 거의 바로 내 화면에 보여요. 방 패널의 초록 점이 "실시간 연결됨" 상태예요.
- 바로 연결이 안 되는 네트워크(일부 회사·학교 와이파이 등)에서는 서버를 거쳐 1~2초 간격으로 받아요. 이때도 게임은 똑같이 진행돼요.
- 바로 연결을 맺을 때 서로를 찾아주는 데에는 PeerJS의 무료 공개 중계 서버를 써요. 게임 내용은 브라우저끼리 직접 주고받고, 기준이 되는 기록은 계속 Netlify 서버에 남아요.
- 누가 자리를 비우면 방장 화면에 **이 차례 넘기기** 버튼이 나와요.
- 새로고침하거나 창을 닫았다 열어도 같은 기기·같은 브라우저면 원래 자리로 돌아가요.

## 소리

배경음악(굿거리장단에 가야금 느낌 가락을 얹은 자작 곡)과 효과음은 음원 파일 없이 브라우저가 바로 만들어요. 화면 오른쪽 아래 스위치로 각각 끄고 켤 수 있고, 기기마다 설정이 기억돼요. 브라우저 정책 때문에 화면을 한 번 누른 뒤부터 소리가 나요.

## 사용량

바로 연결이 된 상태에서는 각 화면이 4초에 한 번만 서버를 확인해요(안전장치). 바로 연결이 안 되면 1.2초마다 확인해서 호출이 늘어나요. 3명이 바로 연결된 채로 한 시간 하면 서버 함수 호출이 대략 3천 번 안팎, 연결이 안 되면 7천~9천 번 정도예요. Netlify 무료 플랜은 한 달에 쓸 수 있는 양이 정해져 있으니, 자주 할 때는 Netlify의 사용량 화면을 가끔 확인해 주세요.

## 방 데이터

방 정보는 Netlify Blobs의 `yutgil-rooms` 저장소에 방 코드 이름으로 저장돼요. 오래된 방이 자동으로 지워지지는 않지만 방 하나가 몇 KB라 쌓여도 부담은 거의 없어요.

## 내 컴퓨터에서 미리 해보기 (선택)

```bash
npm install
npx netlify-cli dev
```

터미널에 나오는 주소(보통 `http://localhost:8888`)로 들어가면 방 서버까지 함께 돌아가요. 같은 컴퓨터에서 브라우저 창 두 개(하나는 시크릿 창)로 열면 혼자서도 친구와 하기를 시험해 볼 수 있어요.
